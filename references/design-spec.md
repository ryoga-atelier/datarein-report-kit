# デザイン仕様（design-spec）

正本は scripts/build_report.py の実装。本書はその設計意図の説明で、変更時は両方を揃える。

## 色（意味を固定）

| トークン | 値 | 用途 |
|---|---|---|
| INK | #172F43 | 本文・表ヘッダー地 |
| TEAL | #176A71 | 基準以上・強み・見出しアクセント・総合点(5点以上) |
| AMBER | #9A6841 | 基準未満・課題・総合点(5点未満) |
| MUTED | #5C6D7A | 補足・注記・軸ラベル |
| LINE/PALE/HEAD | #D8E1E6 / #F0F5F6 / #F4F7F8 | 罫線・淡地 |
| 軸色 | TEAL / #64959B / #6D7F9A | 3軸の系列色（個人バーと全体グラフで共通） |

色は装飾ではなく判定の意味を運ぶ。青緑=基準以上、琥珀=基準未満、破線=基準値。これを崩す変更はしない。

## タイポグラフィ階層（4層固定）

| 層 | サイズ | 用途 |
|---|---|---|
| ページタイトル | 21.5〜24pt Bold | 氏名・章題 |
| h1 | 12pt Bold INK | 節見出し |
| h2 | 10pt Bold TEAL | 小見出し |
| ラベル | 8pt Bold MUTED | 表の左列ラベル |

本文8.8〜9.6pt・行間比146〜156%。表セル9.0pt。注記7.8pt、フッター7.05pt。8pt未満は補助情報のみ。

## ページ構成（変更しない骨格）

- 個人5ページ: ①総合サマリー（大型点数＋ゲージ＋役回り枠＋強み/課題2列＋3軸バー） ②スコアプロファイル（内訳表＋合計式＋N名分布＋尺度11段◀本人） ③経過所見＋観点別（行動/解釈/含意/尺度位置） ④人材像＋任せ方＋リーダー適性＋リスク ⑤実務活用イメージ＋関わり方＋確認観点＋ミニ適性マップ＋注記
- 全体4ページ: ①方法（着眼点・配点・判断ルール） ②尺度アンカー＋総合点位置づけ＋N名比較グラフ ③評価サマリー＋役回り表＋配置判断 ④適性マップ（拡大）＋象限の読み方＋注記
- 結合PDFは全体版が先頭（経営者は結論から読む）。フッター2行の免責は全ページ共通。

## 図の仕様と守るべき点

- ゲージ／バー／分布図: 必ず基準の破線を入れる。0.5点差を視覚で誇張しない。
- 尺度表: 本人行を淡地＋「◀ 本人」で示す。半点は上下2行を示す。
- 適性マップ: 横軸=作る側⇄使う側、縦軸=伴走前提⇄自走。定性配置であり測定値ではない注記を必ず添える。ラベルは白帯を敷いて破線と重ねない。個人版ミニマップは本人のみ強調色。
- レーダーチャートは使わない（配点4-2-4が不揃いで、面積が視覚的に嘘をつくため）。

## 品質基準（validate.py が検査）

ページ使用率50〜98%（推奨60〜97%）。個人4〜6ページ（目標5）、全体3〜6ページ（目標4）。行の重なり・欠けはPNG目視で確認する。
